# Predictive Maintenance in Nuclear Power Plant Subsystems

Data Analysis and Machine Learning

This project uses the **Nuclear Power Plant Alarm Dataset** (IEEE DataPort) to explore alarm behaviour across simulated plant subsystem and to train a machine learning model that anticipates a high-temperature coolant alarm (`TAVG_HI`) in the Primary Coolant System before it fully triggers  a working example of predictive maintenance applied to process-safety data.

## 📊 Dataset

**Nuclear Power Plant Alarm Dataset**
Gianluca Manca (ABB Corporate Research Center, Germany) & Franz C. Kunze (Ruhr University)
IEEE DataPort, DOI: [10.21227/g2fa-9y43](https://dx.doi.org/10.21227/g2fa-9y43)

The dataset is derived from PCTRAN-simulated nuclear power plant accident scenarios (Qi et al., 2022, *Scientific Data*) and adds alarm time series generated by applying high/low thresholds to each process variable, tuned across 10 different missed-alarm/false-alarm trade-off configurations.

For this project, one 302-step simulation run was used, containing 192 binary alarm flags (96 sensors × HI/LO) plus a `TIME` column, alongside the 10 corresponding threshold-configuration profiles.

**Methodology note:** The dataset does not publish an official subsystem taxonomy. Sensors were grouped into four working subsystems (Primary Coolant System, Secondary Steam Cycle, Control Rod Drive Mechanism, Emergency Diesel Generators) using standard NPP tag-naming conventions, as a working assumption for subsystem-level analysis  not a verified engineering diagram of the simulated plant.

## 🔍 Project Workflow

1. **Data Preprocessing** — extracted from `.7z` archives, checked for missing values and duplicates (none found), confirmed final shapes (302×193 alarm data, 10×97 threshold data).
2. **Exploratory Data Analysis** — threshold variability across configurations, alarm activity by subsystem, most frequently triggered alarms, and identification of `TAVG_HI` as the one alarm with a genuine normal→abnormal→normal transition.
3. **Machine Learning** — binary classification of `TAVG_HI` using Random Forest and Gradient Boosting (80/20 stratified split, 191 input features).
4. **Evaluation** — both models reached 98.36% accuracy; Random Forest was selected for its interpretable, subsystem-consistent feature importances (`VOL_HI`, `RM2_HI`, `LVPZ_HI`, `HTR_HI`).
5. **Dashboard** — a Gradio interface lets a user toggle the top 10 predictive sensors and see a live prediction with probability.

---

## ⚠️ Known Limitations

- The model predicts from **concurrent** sensor states, not lagged/historical ones  it is closer to real-time alarm correlation than true forward-looking failure prediction.
- Based on a **single simulation run** (1 of 1,211 available scenarios), so results are not yet validated across fault classes.
- The alarm class is heavily imbalanced in the test set (3 of 61 rows), so recall (0.67) should be read with that small sample size in mind.
- Subsystem grouping is a reasonable working assumption, not an official dataset label (see Methodology note above).

These are documented in full in Report 2's discussion and conclusion sections, along with suggested next steps.
